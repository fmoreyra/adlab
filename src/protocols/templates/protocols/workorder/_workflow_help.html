¿Emitida o enviada?

{% if variant == "compact" %}
  • Borrador: en preparación; se puede editar.
  • Emitida: revisada y cerrada por el laboratorio; ya no se edita. El veterinario aún no fue notificado.
  • Enviada: el veterinario recibió aviso (correo). Puede marcarse desde borrador o tras emitir.
  • Facturada: cobro registrado en el ciclo administrativo.
{% else %}

Son pasos distintos: emitir es confirmación interna; enviar notifica al veterinario.

  • Emitir OT — Cierra la OT para el laboratorio (no se editan montos ni ítems). Útil para revisar antes de avisar al cliente.
  • Marcar como enviada — Dispara el correo y la notificación al veterinario. Se permite desde borrador si la OT ya está correcta.

Al crear una OT queda en borrador. Emitir es opcional: si no necesitás una revisión interna, podés enviarla directamente.

{% endif %}
